lfs-rl · seeking compute sponsorship

A training environment where AI agents fix real broken Linux systems, and the reward is whether the system actually works.

Most benchmarks check whether an answer looks right. Here, a program is compiled and run inside the repaired system. If it produces the wrong output, the agent fails. There is nothing to fake.

What it already proved

A small open model (3 billion parameters) went from 0% to 58% on broken systems it had never seen before.

Crucially, we can prove it reasoned rather than memorised: each repair was hidden behind a detail that exists only inside that specific machine, and we checked every successful run to confirm the model looked it up before acting.

Getting there also produced a reusable finding: what training examples must contain for an agent to learn diagnosis instead of recall. Three designs failed first, each for a reason we could read in the transcripts.

The harder tier, and why it matters

Real incidents are hard because the damage is done early and the symptom appears much later, somewhere else. So we built that: a fault is planted in one software package, the build continues, and the failure surfaces up to fourteen packages later. The agent is told nothing about where to look.

A frontier model solved one of these, but it took real detective work: rebuilding a library from source and comparing it byte by byte against the installed copy to find a single sabotaged function. That is the kind of task current models are still weak at, which is exactly what makes it worth training on.

Why this is unusual

  • Cheap to run. About 1.6 seconds per attempt, so training can sample thousands of them. Comparable environments need minutes and a Kubernetes cluster.
  • Cannot be gamed. The grading runs outside the agent's reach and we have attacked it ourselves.
  • It measures honestly. It has produced published negative results, including two of our own hypotheses that turned out to be wrong.
  • Nobody else is here. Every comparable project is an evaluation benchmark. None is built for training.

What we are asking for

GPU compute to run the training programme on the hard tier. A first meaningful run is roughly $300; a thorough programme, a few thousand.

Everything above was built for under $20 of GPU time, on one laptop. The environment, the fault generator, the training pipeline and every result are already working and public.
